# Presidente da República

[← Projeto de Governo](../../README.md) · [Quem faz o quê](../../COMPETENCIAS.md)

**Esfera:** União · **Poder:** executivo · **Mandato:** 4 anos

## O que o cargo faz

Chefia o governo federal: executa as políticas nacionais, propõe o orçamento da União, nomeia ministros, edita decretos e medidas provisórias, sanciona ou veta leis.
