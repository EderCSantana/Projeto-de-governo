# Governador(a)

[← Projeto de Governo](../../README.md) · [Quem faz o quê](../../COMPETENCIAS.md)

**Esfera:** Estado · **Poder:** executivo · **Mandato:** 4 anos

## O que o cargo faz

Chefia o governo do estado: executa as políticas estaduais, propõe o orçamento, nomeia secretários, comanda as polícias e sanciona ou veta leis estaduais.
